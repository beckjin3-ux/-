# CREW ARCHIVE

블랙 + 버건디 테마의 크루 작업 관리 PWA 프로토타입입니다.

## 실행
- `index.html`을 브라우저에서 열어 화면과 기본 흐름을 확인할 수 있습니다.
- 설치 기능과 오프라인 캐시를 테스트하려면 HTTPS로 호스팅하거나 localhost에서 실행해야 합니다.
- iPhone: Safari에서 배포된 주소 접속 → 공유 → 홈 화면에 추가
- Android/데스크톱: 지원 브라우저의 설치 메뉴 또는 앱 설치 버튼

## 현재 포함
- 대시보드 및 마감 현황
- 업무 등록 및 담당자/마감일 기록
- 작업물 제출 흐름(파일명 또는 링크 기록)
- 총괄진 승인 / 수정 요청
- 승인된 창작물 아카이브
- 반응형 모바일 UI 및 PWA 설치 구성
- 브라우저 로컬 저장

## 운영 전 필요한 작업
현재 버전은 시연용 프론트엔드이며 실제 다중 사용자 서비스가 아닙니다. 팀원들이 같은 데이터를 공유하려면 서버/API, 계정 로그인, 역할별 권한 검증, 파일 업로드 저장소, 알림, 데이터 백업을 연결해야 합니다. 승인 권한은 실제 서비스에서 서버 측으로 강제해야 합니다.
